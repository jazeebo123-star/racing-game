# 🏎️ Racing Game (Basic Foundation)

A clean, basic 3D car on an asphalt race track with arcade physics and 3rd-person chase camera.

---

## 🎮 Controls

| Key | Action |
|---|---|
| **W** or **Up Arrow** | Accelerate forward |
| **S** or **Down Arrow** | Brake / Reverse |
| **A** or **Left Arrow** | Steer Left |
| **D** or **Right Arrow** | Steer Right |
| **R** | Reset car position to start |
